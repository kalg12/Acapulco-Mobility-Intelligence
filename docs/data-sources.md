# Data Sources

## Acapulco Mobility Intelligence

This document tracks potential datasets for the project.

## Source 1 — INEGI

Organization: Instituto Nacional de Estadística y Geografía

Dataset: Estadística de Transporte Urbano de Pasajeros

URL:
https://www.inegi.org.mx/programas/transporteurbano/

Data type:
Public transportation statistics.

Status:
Pending dataset inspection.

Research relevance:
Historical context for public transportation.

Limitations:
Not a direct source of taxi or ride-hailing fares.
